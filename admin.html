Connecting Your Supabase Database

  1. Create a free project at supabase.com.
  2. Go to SQL Editor in your Supabase Dashboard.
  3. Copy and paste the entire script from supabase_setup.sql located in your project root, then click Run.
  4. Go to Project Settings -> API, and copy your Project URL and anon public API key.
  5. Open assets/js/supabase-config.js in this project and paste your URL and Anon Key.
